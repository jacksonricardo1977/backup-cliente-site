Política de Privacidade - Backup Cliente

Última atualização: 30 de outubro de 2026.

1. Finalidade

O Backup Cliente é uma ferramenta privada utilizada para realizar cópias de segurança de arquivos em armazenamento na nuvem.

2. Dados acessados

O aplicativo utiliza a API do Google Drive para armazenar e consultar arquivos de backup autorizados pelo titular da conta.

3. Criptografia e segurança

Os arquivos são criptografados pelo Restic antes do envio ao Google Drive. A senha de criptografia é mantida separadamente e não é enviada ao Google Drive.

4. Compartilhamento

Os dados não são comercializados nem compartilhados com terceiros para publicidade.

5. Armazenamento e exclusão

Os backups permanecem armazenados na conta Google Drive autorizada, conforme a política de retenção definida pelo responsável pelo sistema.
